# Descargar GalaxyCraft

La versión actual es **`galaxycraft-0.2.0.jar`**, con los recursos y funciones de
la fase 5. La versión 0.1.0 se conserva como archivo histórico. Instala solo una
versión a la vez en `mods`. Ambas necesitan Minecraft **1.21**, NeoForge
**21.0.167** y Java **21**.

Descarga el archivo desde GitHub usando **Download raw file**.

SHA-256 de la versión 0.2.0, validada con 47 pruebas y generación en servidor:

```text
ac5911ef50225833f83b15f96fc1887492c9c94fdee2810ab11587f97593c2bc
```

La comprobación visual del HUD, el audio y el viaje con jugador sigue pendiente.

## Versión anterior

`galaxycraft-0.1.0.jar` es el mod compilado para Minecraft **1.21**, NeoForge
**21.0.167** y Java **21**, a partir del código del commit `6cf7b62`.

Descarga el archivo desde GitHub usando **Download raw file** y colócalo en
la carpeta `mods` de tu instalación de NeoForge. No necesitas compilarlo.

SHA-256:

```text
997d5cc092ae0c9d01dac506e2255888db6d2d8bf585dd5553c62115d335e922
```

La compilación y las 41 pruebas automatizadas pasaron. La interacción de la
interfaz y el viaje completo con un jugador todavía requieren pruebas manuales.
