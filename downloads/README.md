# Descargar GalaxyCraft

La versión actual es **[`galaxycraft-0.5.0.jar`](galaxycraft-0.5.0.jar)**:
misiones con GUI, módulos de supervivencia, bases herméticas, energía FE, rover
y estaciones en 29 órbitas. Conserva navegación, arte y 145 estructuras anteriores.
Las versiones 0.1.0 a 0.4.1 quedan como archivo histórico.
Instala solo una versión a la vez en `mods` y haz una copia de tu mundo.
Todas necesitan Minecraft **1.21**, NeoForge
**21.0.167** y Java **21**.

Descarga el archivo desde GitHub usando **Download raw file**, o utiliza la
[descarga directa](https://github.com/vic17usd/mod-minecraft/raw/refs/heads/main/downloads/galaxycraft-0.5.0.jar).

SHA-256 de 0.5.0, compilada y validada con 209 pruebas JUnit y nueve GameTests:

```text
7c45fe78a6c0dde367048db28b7fe602246f3a9f47960e4bd33d441c932a0e7e
```

La revisión visual y una sesión con cliente real siguen pendientes. No necesitas
Curios. Pulsa **J** para misiones, **G** para traje/módulos y **H** cerca del cohete
para navegación. Actualiza tanto el cliente como el servidor. Consulta la
[guía de expansión](../docs/EXPANSION_SUPERVIVENCIA.md) para aire, FE, rover y órbitas.

## Versión anterior

`galaxycraft-0.1.0.jar` es el mod compilado para Minecraft **1.21**, NeoForge
**21.0.167** y Java **21**, a partir del código del commit `6cf7b62`.

Descarga el archivo desde GitHub usando **Download raw file** y colócalo en
la carpeta `mods` de tu instalación de NeoForge. No necesitas compilarlo.

SHA-256:

```text
997d5cc092ae0c9d01dac506e2255888db6d2d8bf585dd5553c62115d335e922
```

La compilación y las 41 pruebas automatizadas pasaron. La interacción de la
interfaz y el viaje completo con un jugador todavía requieren pruebas manuales.
