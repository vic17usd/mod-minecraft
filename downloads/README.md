# Descargar GalaxyCraft

`galaxycraft-0.1.0.jar` es el mod compilado para Minecraft **1.21**, NeoForge
**21.0.167** y Java **21**, a partir del código del commit `6cf7b62`.

Descarga el archivo desde GitHub usando **Download raw file** y colócalo en
la carpeta `mods` de tu instalación de NeoForge. No necesitas compilarlo.

SHA-256:

```text
997d5cc092ae0c9d01dac506e2255888db6d2d8bf585dd5553c62115d335e922
```

La compilación y las 41 pruebas automatizadas pasaron. La interacción de la
interfaz y el viaje completo con un jugador todavía requieren pruebas manuales.
